Basé sur Debian 13 Trixie

Le bureau Linux que vous attendiez.

Citron OS est une distribution live x86_64 complète, alliant la robustesse de Debian à une interface GTK légère et réactive.

Télécharger Code Source

🖥️ Bureau GTK Natif

Un environnement de bureau rapide, propre et épuré. Propulsé par un shell personnalisé compilé en C (citron-shell.c).

✨ Splash Plymouth

Un démarrage visuel soigné avec un splash screen animé, des points pulsants et une barre de progression fluide dès l'amorçage.

💾 Session Persistante

Configurez une partition nommée persistence sur votre clé USB pour conserver vos profils et mots de passe.
